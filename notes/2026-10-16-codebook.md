# Licorice gargle trial: codebook (as sent by the client)

Source: `medicaldata` R package, dataset `licorice_gargle` (MIT), contributed
by Amy S. Nowacki; Ruetzler et al., Anesth Analg 2013;117:614-21. 236
patients enrolled; the public file has one row per patient.

| Variable | Meaning | Codes |
|---|---|---|
| preOp_gender | Sex | 0 = male, 1 = female |
| preOp_asa | ASA physical status | 1, 2, 3 |
| preOp_calcBMI | Body mass index | kg/m2 |
| preOp_age | Age | years |
| preOp_mallampati | Mallampati class | 1-4 |
| preOp_smoking | Smoking | 1 = current, 2 = past, 3 = never |
| preOp_pain | Preoperative sore throat | 0 = no, 1 = yes |
| treat | Gargle | 0 = sugar water, 1 = licorice |
| intraOp_surgerySize | Surgery size | 1 = small, 2 = medium, 3 = large |
| extubation_cough | Cough at extubation | 0 = none to 3 = severe |
| pacu30min_cough | Cough, 30 min after PACU arrival | 0-3 |
| pacu30min_throatPain | Sore throat at rest, 30 min | 0-10 |
| pacu30min_swallowPain | Sore throat on swallowing, 30 min | 0-10 |
| pacu90min_cough | Cough, 90 min | 0-3 |
| pacu90min_throatPain | Sore throat at rest, 90 min | 0-10 |
| postOp4hour_cough | Cough, 4 h after surgery | 0-3 |
| postOp4hour_throatPain | Sore throat at rest, 4 h | 0-10 |
| pod1am_cough | Cough, first postoperative morning | 0-3 |
| pod1am_throatPain | Sore throat at rest, first postoperative morning | 0-10 |
