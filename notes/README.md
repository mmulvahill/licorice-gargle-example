# Notes

Intake notes, meeting notes and client emails, saved as received: one file
per meeting or message, named `YYYY-MM-DD-<topic>.md`. They are where the
client's words come from, so a quote in the report must appear here.

Never edit a note after the fact; add a new file instead. Keep identifiable
data out. If your notes should not live in the repo, paste them to Claude
instead and let the decisions they contain flow into DECISIONS.md and the
plan.
